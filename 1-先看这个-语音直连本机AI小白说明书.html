对着电脑说话，让 AI 替你干活

装好以后，你会有一个只有自己能打开的网页。按住按钮说一句话，你电脑里的 AI 就照办；它干完活，用小米「冰糖」把结论念给你听。想打断就喊一声「停」。

核心用法：不用敲命令、不用看代码。把整个压缩包（或解压后的文件夹）丢给你的 AI，复制下面那句提示词发出去就行。

一、这是什么，装完能看到什么效果

常见的语音助手都住在大公司的服务器上：把你说的话传上去，再让那边的模型回答，跟你自己电脑里的项目、文件、规矩完全是两回事。这个包做的正好相反——它只当你的「话筒和嗓子」，听懂和念出来都在你自己这台电脑上，真正干活的还是你电脑里的 Pi、Claude Code、Kimi。

没装之前 想派活只能一个字一个字敲；说给手机助手听，它不懂你的项目，还得你复制粘贴一遍。
装好之后 按住大按钮随口说一句，原话直接进了 AI 的对话里；它干活的时候你松开手就能听，结论会被念出来。
做完最终效果：你按住说话「我生意目录下面有几个大类」，几秒后它把答案念给你听——手不用离开咖啡杯，键盘一下都不用碰。

二、动手前只需准备

1. 一台 Mac 电脑 只支持 macOS。电脑里要已经装好一个能干活的 AI（Pi / Claude Code / Kimi Code 任意一个）。
2. 一个能改文件的 AI 助手 Codex / WorkBuddy / Pi / Claude Code 都行。装东西、改配置、自检全交给它，你不动手。
3. 一个语音 Key + 麦克风 去小米 MiMo 开放平台注册，拿一个 API Key（用来把文字念成声音，目前限时免费）；第一次说话时浏览器会问能不能用麦克风，点「允许」。

听写是在你电脑上离线跑的，不用另外买转写服务、也不上传录音；Key 只存在你自己电脑里，不会写进这份说明书。

四、哪些时候 AI 会停下来等你

下面这几件事只跟你自己有关，AI 不会替你决定，做到这里会停下来问你：

1. 向你要小米 MiMo 的 API Key

去小米 MiMo 开放平台生成一个 Key，直接发给 AI，让它帮你存到电脑里。这个 Key 只贴给你的 AI，别发群里、别发网上。

2. 浏览器问「是否允许使用麦克风」

点「允许」。这是唯一必须你自己点的地方，点完以后就不用再点了。要是点成了「不允许」，在地址栏左边的设置里改回来，或者让 AI 带你重开一次。

3. 第一次实机试说一句

AI 会让你对着页面说一句「你好，一加一等于几」。听到它先应一声「收到」、再把答案念出来，就算彻底通了。这一步只能你来，AI 没嗓子。

五、卡住了怎么办

坑 1：按住说了半天，页面既不显示字也没反应

十有八九是麦克风权限被拒了，或者网页不是在这台装好服务的电脑上打开的。先看地址栏左边有没有被划掉的麦克风图标。

排错提示词
我按住说话没有反应，页面上也不出字。请按 2 号文档里的验收清单逐项检查：麦克风权限、语音服务有没有在跑、听写那一环能不能单独跑通。查出来直接修，修好后带我重新说一句。
坑 2：字出来了，但一点声音都没有

多半是浏览器把自动播放拦住了，或者系统静音、音量为 0。先在页面上随便点一下，再检查电脑音量。要是还没声，就让 AI 查语音 Key 和合成的设置。

排错提示词
语音有文字回复，但完全没有声音。请从三处挨个排查：语音服务状态和日志、MiMo 的 Key 有没有存对、网页这边能不能正常播放。修好以后放一段测试音让我确认。
坑 3：它把我的话听错了，比如把「Claude」听成「克劳德」、「派」听成 Pi

这是本地听写对英文名不熟，不是坏了。跟 AI 说一句，让它把正确的叫法加进「热词表」，以后就听得准了；自己说的时候稍微连起来说，别一个字一个字断。

排错提示词
我说话被听成了别的词，比如把「Claude」听成「克劳德」、「Pi」听成「派」。请把正确的说法加进热词表，注意别把平时说话里的「派」也一起改坏（只在「切到 / 用」后面才换），改完让我再说一句试试。
还是不行？点这里，让 AI 从头重来一遍

先跟 AI 说：「把语音直连这套停掉、按 2 号文档重新装一遍，装完自己跑一遍接口测试再叫我。」重装不会动你的项目文件和对话记录。

如果它反复说某个东西「装不上」，把那句报错原文复制给 AI，别自己猜着删东西——删错了会更难修。
