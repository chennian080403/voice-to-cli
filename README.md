# 语音直连本机 AI · 按住说话直接派活

不想一直敲键盘，又懒得复制粘贴转文字？这套本地工具用离线 **SenseVoice** 听写你的语音，直接把原话送进本机正在跑的 **Pi / Claude Code / Kimi Code** 前台会话，并用语音念出关键回复。

## 包里有什么

- `1-先看这个-语音直连本机AI小白说明书.html`：原理与效果说明
- `2-发给你的AI-让它照着做.md`：给你的 AI 自动检测声卡/模型并跑起来
- `3-参考脚本（作者机器上在跑的，AI照着改）/`：包含服务端 `server.py`、前端 `index.html`、配置模板与启动脚本
